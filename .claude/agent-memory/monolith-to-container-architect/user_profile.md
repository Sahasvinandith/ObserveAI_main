The user is containerizing ObserveAI, a real-time multi-camera CCTV surveillance system.
They have already tagged the monolith as `v1.0-monolith` on GitHub and created a `feature/containerize` branch.
The project already has a browser-based web UI (FastAPI + React) added in the latest commit,
which significantly simplifies containerization by eliminating the PyQt6 GUI dependency.
