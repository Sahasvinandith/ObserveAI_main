ISSUE FOUND: Person Projection Bug
================================================================================

PROBLEM:
  When a person is detected in camera frame, the BEV shows their position 
  at the CAMERA LOCATION instead of the ACTUAL PERSON LOCATION.
  
  Example:
    Real person position: (140, 110) on map
    Cheap camera at:      (243.5, 56.0)
    
    Debug output shows person at: (243.5, 56.0) ← WRONG!
    Should be at:                 (140, 110)    ← CORRECT

ROOT CAUSE IDENTIFIED:
  The project_bbox_to_world() function was using bbox CENTER (head/chest)
  instead of bbox BOTTOM (feet on ground).
  
  - Homography assumes ground plane projection (Z=0)
  - Person head is 1.8m above ground (off by ~2 meters)
  - Must project from feet contact point, not head
  
  Code was:
    cy_bottom = cy_frame  # Using center - WRONG!
  
  Should be:
    cy_bottom = bbox[1] + bbox[3]  # Using bottom - CORRECT!

FIX APPLIED:
  ✅ File: components/HomographyProjector.py
  ✅ Line: 172-176
  ✅ Change: Use bbox.bottom instead of bbox.center

IMPACT:
  - Person projections now from ground contact point
  - Should reduce positioning error from 2-5m to <0.5m
  - Persons should move naturally on map as they move in reality
